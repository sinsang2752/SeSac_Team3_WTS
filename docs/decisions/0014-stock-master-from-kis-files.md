# ADR-0014: 종목 마스터는 KIS 종목정보 파일로 동기화한다

- 상태: 채택
- 날짜: 2026-10-06
- 관련: CLAUDE.md §0-4, §57.1, §61.1 Phase 8-1. 대체: `application.yml`의 `market.stocks` 고정 5종목

## 맥락

Phase 7까지 종목 목록은 `application.yml`에 적은 5종목이었다. 검색도 관심종목도 그 안에서만 됐다.
Phase 8은 KOSPI · KOSDAQ 상장 주권 전체(약 2,700개)를 다룬다.

## 결정

1. **원천은 한국투자증권이 공개하는 종목정보 파일이다.** `kospi_code.mst.zip`, `kosdaq_code.mst.zip`.
   인증이 필요 없다. KIS 앱키를 쓰지 않는다.
2. **market DB의 `stocks` 테이블이 원본이다.** 기동 시와 매 영업일 08:00(KST)에 동기화한다.
   파일에서 사라진 종목은 지우지 않고 `listed=false`로 둔다. 주문 · 포지션 · 관심종목이 그 코드를 참조한다.
3. **스냅샷은 KIS 원본 zip을 그대로 저장소에 둔다** (`market-service/src/main/resources/master/`, 224KB).
   CLAUDE.md §57.1은 CSV 스냅샷을 적었지만 원본을 택했다. 다운로드와 스냅샷이 같은 파서를 타므로
   형식이 하나뿐이고, 스냅샷 갱신은 파일 두 개를 다시 받는 것으로 끝난다
   (`infra/scripts/update-stock-master-snapshot.sh`).
4. **mock 모드는 네트워크를 쓰지 않는다.** 비어 있으면 스냅샷으로 채우고 끝이다 (§0-4).
   kis 모드는 비었거나 20시간 넘게 지났으면 내려받고, 실패하면 기존 마스터를 지킨다.

## 파일 형식에서 확인한 것

- 한 줄 = 앞부분(단축코드 9 · 표준코드 12 · 한글명 가변) + 뒷부분(고정 길이).
  이름 길이가 제각각이라 **줄 끝에서부터** 자른다.
- 공식 예제(open-trading-api `stocks_info`)의 228 · 222는 **줄바꿈까지 센 값**이다.
  실제 데이터는 KOSPI 227자, KOSDAQ 221자다. 228로 자르면 모든 필드가 한 칸씩 밀린다.
- 필드 오프셋(뒷부분 기준)은 공식 예제의 필드 폭에서 계산했고, 실제 값(삼성전자 기준가 276,000원)으로 검증했다.

  | 필드 | KOSPI | KOSDAQ |
  |---|---|---|
  | 증권그룹 (ST = 주권) | 0 | 0 |
  | 기준가 (9) | 41 | 36 |
  | 거래정지 (Y/N) | 60 | 55 |
  | 전일 기준 시가총액, 억원 (9) | 212 | 206 |

- **종목코드는 숫자 6자리만이 아니다.** 2024년 이후 상장 종목은 영문 대문자가 섞인다(`0001A0`, `00088K`).
  2026-10 기준 주권 2,719개 중 85개다. 주문 · 관심종목의 `\d{6}` 검증을 `[0-9A-Z]{6}`으로 바꿨다
  (`common`의 `StockSymbol`). ETN은 7자리(`Q500067`)라 상품을 넓힐 때 다시 본다.
- 기준가가 0으로 오는 종목이 있다(신규 상장 직후 등). 0원이 아니라 `null`로 둔다.

## 형식이 바뀌면

파서는 잘못 자른 값을 넣는 대신 예외를 던진다. 동기화는 실패하고 기존 마스터가 남는다.
레이아웃이 어긋나 주권을 하나도 찾지 못한 경우도 실패로 다룬다. 실제 파일에서 자른 테스트 픽스처가
레이아웃 변화를 먼저 잡는다.

## 검색 정렬

종목코드 일치 → 종목코드로 시작 → 이름으로 시작 → 그 밖의 부분일치, 같은 순위 안에서는 **시가총액이 큰 순**이다.
이름순만 쓰면 `utf8mb4_0900_ai_ci`에서 영문이 한글보다 앞서 "삼성"을 쳤을 때 삼성E&A가 삼성전자보다 먼저 나온다.

## 결과

- 시세 공급자(Mock · KIS)는 Phase 8-1 동안 `market.pinned-symbols`(5종목)만 구독한다.
  마스터 전체를 구독하면 KIS 등록 한도를 넘고, Mock은 아무도 보지 않는 2,700종목을 매초 만든다.
  나머지 종목의 시세는 Phase 8-2(계층형 구독)에서 붙는다. 그 전까지는 `503 MARKET_PRICE_UNAVAILABLE`이다.
- 프론트는 전체 목록을 받지 않는다. 검색은 서버에서, 이름은 `?symbols=`로 필요한 종목만 묻는다.
